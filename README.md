# tokihomu-lab（ときほむラボ）🐾

子供向けビジュアルプログラミング学習Webゲームのプロトタイプです。  
Google Blocklyでブロックを組み立て、画面上の白黒ハチワレ猫「トキ」を動かして、相棒のクリーム色長毛猫「ホムラ」をつかまえる「おにごっこ」ゲームです。

👉 **[Webブラウザで今すぐあそぶ（GitHub Pages）](https://eno314.github.io/tokihomu-lab/)**

---

## 🌟 主な特徴

- **完全クライアントサイド動作**: HTML / CSS / JavaScript のみで構成され、Webブラウザで `index.html` を開くだけで即座に動作します。
- **子供向けのやさしい表記**: 「まえに 1マス すすむ」「みぎを むく」「〇かい くりかえす」など、ひらがなを中心とした直感的なブロック構成。
- **ステップ実行アニメーション**: 1マスずつのスムーズな移動・回転アニメーションと、実行中ブロックのハイライト表示。
- **モード＆ステージ機能**:
  - **🐾 おにごっこモード（きほん）**:
    - **レベル1**: 障害物のない平坦な盤面で、基本操作（前進・回転・繰り返し）を練習。
    - **レベル2**: 盤面にダンボール箱（📦）の障害物が登場！ぶつからないように迂回するルートをプログラミング。
    - **レベル3**: ホムラがお散歩しながら逃げるよ！トキが命令（進む・向く）を実行するたびに左右へ往復移動するホムラの動きを予測してつかまえよう！
    - **レベル4**: レベル2と3の合体ステージ！ダンボール箱（📦）を上手によけながら、てくてく逃げるホムラをつかまえよう！
  - **🦐 ぬいぐるみあつめモード（おうよう）**:
    - **レベル1**: 盤面のまんなかにあるエビのぬいぐるみ（🦐）を「ひろう」で回収して、右下にいるホムラに届ける基本練習。
    - **レベル2**: ダンボール障害物を避けつつ、2つのぬいぐるみ（🦐 エビ・🎾 ボール）をすべて集めてからホムラへ行く応用ステージ。
- **安心のフィードバック演出**:
  - かべや障害物（ダンボール）にぶつかった時の「ブルブルッ」とした衝突演出とメッセージ
  - ぬいぐるみのないマスで「ひろう」を実行したときの「あれ？ なにもないよ？（キョロキョロ）」演出
  - ぬいぐるみを全部集めずにホムラに着いたときの「ぬいぐるみが まだ たりないニャ〜！」アドバイス
  - ゴール到達時のピョンピョン跳ねる勝利アニメーションとお祝いモーダル（次のレベルへワンクリックで進めます）
- **スピード切り替え**: 「ゆっくり」「ふつう」「はやい！」から好みの速度でステップ実行可能。

## 🚀 遊び方（起動方法）

特別なビルドやサーバー設定は不要です。

1. 本リポジトリ内の `index.html` をお好みのWebブラウザ（Google Chrome, Edge, Safari, Firefoxなど）で開きます。
2. 上部のタブで「🐾 おにごっこ」または「🦐 ぬいぐるみあつめ」モードを選びます。
3. 左側のワークスペースにブロックをドラッグ＆ドロップして並べます。
4. 右上の「うごかす！」ボタンを押すと、トキがプログラム通りに動き始めます。
5. 「リセット」ボタンでいつでもスタート地点（0, 0）に戻せます。

## 🧩 使えるブロック

| ブロック | 説明 |
| :--- | :--- |
| **まえに 1マス すすむ 🐾** | 現在向いている矢印（▲）の方向へ1マス前進します。 |
| **みぎを むく ↷** | 時計回りに90度向きを変えます。 |
| **ひだりを むく ↶** | 反時計回りに90度向きを変えます。 |
| **ぬいぐるみを ひろう 🐾** | いまいるマスにある目標物（ぬいぐるみ）を拾います。（ぬいぐるみあつめモードで登場） |
| **〇かい くりかえす 🔁** | 中に入れたブロックを指定した回数（2〜8回）繰り返します。 |

## 🧪 UIテストの実行 (Playwright)

本プロジェクトでは Playwright を用いた UI 自動テストを導入しています。

### ローカルでのテスト実行

```bash
# 依存パッケージのインストール
npm install

# Playwright ブラウザのインストール
npx playwright install --with-deps chromium

# UIテストの実行
npm test

# UIモードでインタラクティブに実行
npm run test:ui
```

> **Podman を利用して実行する場合**:
> ```bash
> podman run --rm -it -v $(pwd):/work:Z -w /work mcr.microsoft.com/playwright:latest npx playwright test
> ```

## 🚀 CI/CD パイプライン

GitHub Actions により以下のフローが自動化されています:

1. **Pull Request 作成・更新時**:
   - Playwright による UI テストが自動実行され、リグレッションを防止します。
2. **main ブランチへのマージ・Push 時**:
   - UI テストジョブが実行されます。
   - **UI テストがすべて成功した場合にのみ**、GitHub Pages への自動デプロイジョブが実行されます。
